How the operator works

1
Intake

The operator reads a Telegram request and asks for only the missing facts needed for a useful human decision.

2
Check

It checks the allowed sources: public web, docs, GitHub, status pages, CRM, Sheets, n8n, or a browser workflow.

3
Handoff

It posts a concise summary with evidence, blockers, suggested next step, and the human-only decisions clearly marked.

Human-only by design

The operator does not make pricing commitments, move funds, approve refunds, handle legal/compliance decisions, change production access, or respond to angry customers without escalation.

This is first-line operations leverage, not an unsupervised finance or support agent.
