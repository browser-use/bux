Each example is a prompt you can paste into the Telegram bot or the web terminal. They assume you've completed the [quickstart](/bux/quickstart) and have at least one [Browser Use Profile](/bux/authentication) set up for the relevant site.

## Infrastructure

### Deploy a PR to staging

```
Open GitHub, find PR #235 in browser-use/web-app, comment "/deploy staging",
wait for the deploy bot to react, then paste the staging URL back here.
```

Why BUX: the task spans GitHub, the deploy bot, and a 5-minute wait. Telegram pings you when it's done.

### Roll an Azure resource

```
Sign in to the Azure portal, find the "checkout-prod" App Service,
restart it, and confirm the status flips to Running.
```

Why BUX: Azure's portal is JS-heavy and historically painful for headless agents. BUX runs a real Chrome with your real session.

## Travel and shopping

### Book the earliest flight

```
On Google Flights, find the earliest one-stop flight from ZRH to SFO
on Friday under $900. Add it to my cart on the airline's site
but stop before payment so I can confirm.
```

Why BUX: long-running, multi-site, and you want a human checkpoint before anything is charged.

### Reorder consumables

```
Open Amazon, look at my "Buy Again" list, and order one of each item
that's been delivered in the last 90 days but not in the last 30.
```

## SaaS dashboards

### Pull weekly metrics

```
Sign in to Stripe, export this week's payouts as CSV, and email
the file to finance@example.com via Gmail.
```

### Triage Linear issues

```
Open Linear, list every issue in the "Bugs" project marked Urgent
that hasn't been updated in 7 days, and post the list to our #oncall
Slack channel.
```

## Recipes

### Schedule a recurring run

Pair BUX with the [`schedule`](/cloud/scheduling) feature to fire a prompt on a cron. Common patterns:

- Morning brief: at 8am, summarise overnight GitHub notifications and Slack DMs.
- End-of-day: at 6pm, check that all production deploys have green status checks.

### Hand off mid-task

Start a long task on Telegram, then SSH in to watch the trace:

```bash
ssh bux@<your-bux-id>.bux.browser-use.com
tmux attach -t claude
```

You can scroll back through every step Claude Code took.
