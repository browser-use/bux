<Steps>
  <Step title="Sign in and create a BUX">
    Open [cloud.browser-use.com](https://cloud.browser-use.com), go to **BUX**, click **New Box**. Boot takes 30 to 60 seconds.
  </Step>
  <Step title="Authorise Claude Code">
    The web terminal prints a one-time `claude login` URL. Open it, authorise, paste the token back. The session persists across restarts.
  </Step>
  <Step title="Link a Telegram bot">
    In [@BotFather](https://t.me/BotFather), run `/newbot` and copy the token. Paste it into the BUX dashboard, then send `/start` to your bot.
  </Step>
  <Step title="Send a task">
    From Telegram:

    ```
    Open my GitHub notifications and summarise anything from the last 24 hours.
    ```

    The first run will reply with a [live login URL](/bux/authentication#live-login). Sign in once; future runs reuse the saved profile.
  </Step>
</Steps>

## Other ways to drive your BUX

| Surface       | Best for                                   |
| ------------- | ------------------------------------------ |
| Telegram      | Quick prompts, mobile, push notifications. |
| Web terminal  | Long sessions, copy/paste, debugging.      |
| SSH           | Scripting, file transfer, piping output.   |

All three attach to the same `tmux` session, so you can switch surfaces mid-task without losing state.

## Self-hosting

The VM image and orchestration are open source.

```bash
git clone https://github.com/browser-use/bux
cd bux
make deploy AWS_REGION=us-east-1
```

You'll need an Anthropic API key, an AWS account, and a Telegram bot token. Profiles and logs stay in your account.
