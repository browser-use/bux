This guide takes you from zero to a running BUX VM that you can talk to from Telegram.

## Prerequisites

<Steps>
  <Step title="Browser Use account">
    Sign up at [cloud.browser-use.com](https://cloud.browser-use.com). The free tier is enough to launch your first BUX.
  </Step>
  <Step title="Claude Code access">
    BUX runs Claude Code inside the VM. Make sure your Anthropic account has Claude Code enabled. You will paste the auth token once during setup.
  </Step>
  <Step title="Telegram bot (optional, recommended)">
    Open a chat with [@BotFather](https://t.me/BotFather), run `/newbot`, and copy the bot token. You will hand it to BUX so it can send and receive messages on your behalf.
  </Step>
</Steps>

## 1. Create a BUX

From the dashboard, open **BUX** in the sidebar and click **New Box**.

<Info>
  The first boot takes 30 to 60 seconds. The VM is launched from a prebaked AMI, so Claude Code, Browser Harness, and a headful Chrome are already installed.
</Info>

## 2. Connect Claude Code

When the VM is ready, BUX prints a one-time `claude login` URL in the web terminal. Open it in any browser, authorize, and paste the resulting token back into the terminal. The session persists across restarts.

## 3. Connect Telegram

In the BUX dashboard, paste the bot token from `@BotFather` and click **Link**. Open your bot in Telegram and send `/start`. The first message you receive confirms the link.

<Note>
  The Telegram session keeps Claude Code's full conversation history, so you can pick up a task tomorrow exactly where you left off.
</Note>

## 4. Run your first task

Send a message to the bot:

```
Open google.com and tell me the top result for "browser use".
```

You will see Claude Code stream its reasoning back into the chat, and a screenshot of the final page when the task finishes.

## 5. Try a task that needs login

```
Go to my GitHub notifications and summarise anything from the last 24 hours.
```

The first time you ask this, BUX will reply with a **live browser URL**. Open it, sign in to GitHub once, and BUX captures the cookies into a [Browser Use Profile](/bux/authentication). Subsequent runs skip the login step.
