A BUX VM exposes one Claude Code session through three independent surfaces. You can switch between them mid-task without losing state.

| Surface           | Best for                                              | Latency    | Mobile |
| ----------------- | ----------------------------------------------------- | ---------- | ------ |
| Telegram          | Quick instructions, notifications, hands-off triggers | Low        | Yes    |
| Web terminal      | Watching a long task, reviewing output, copy/paste    | Low        | OK     |
| SSH               | Scripting, file transfer, power-user workflows        | Lowest     | No     |

## Telegram

Once linked, your bot is the fastest way to fire off a task.

- **Persistent context.** Every message goes into the same Claude Code session, so follow-ups like "now do the same for the EU region" work as expected.
- **Inline screenshots.** When the agent finishes a browser step, BUX sends the screenshot back as a Telegram photo.
- **Push notifications.** Long jobs can ping you when they finish, without needing the chat open.

<Note>
  The Telegram session is per BUX, not per chat. If you create multiple BUX VMs, each gets its own bot link.
</Note>

## Web terminal

Open `cloud.browser-use.com/bux` and pick your VM. You get a full xterm with Claude Code attached.

- Useful for **debugging** long traces that scroll past Telegram's message limits.
- The browser session refreshes automatically every 240 minutes for security; reconnect by reloading the tab.
- You can drag-and-drop files into the terminal to upload them to the VM.

## SSH

For local CLI workflows, BUX prints an SSH command from the dashboard.

```bash
ssh bux@<your-bux-id>.bux.browser-use.com
```

- Bring your own dotfiles: `scp` or `rsync` work as expected.
- Useful for piping output into local tools, e.g. `ssh bux@... claude --print "summarise today's PRs" | pbcopy`.
- The SSH key is created on first launch and stored in your Browser Use account.

<Warning>
  Anyone with the SSH key can drive the VM. Treat it like an API token: rotate it from the dashboard if you suspect a leak.
</Warning>

## Switching surfaces mid-task

All three surfaces attach to the same `tmux` session running Claude Code. Start a task in Telegram, watch it scroll in the web terminal, then SSH in to grep the logs. None of them interrupt the others.
