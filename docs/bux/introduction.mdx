## What is BUX?

Browser Use Box (BUX) is a cloud virtual machine that boots in 30 to 60 seconds with **Claude Code** and **Browser Harness** preinstalled. You drive it from Telegram, a web terminal at `cloud.browser-use.com/bux`, or SSH, so the agent can keep working when your laptop is closed.

BUX is built for tasks where a regular browser agent struggles: dashboards behind SSO, multi-step workflows that span hours, and anything you want to kick off from your phone.

  Looking for the launch story and the reasoning behind BUX? Read the [launch blog post](https://browser-use.com/posts/bux-launch-blog).
</Note>

## When to reach for BUX

| You want to...                                                             | Use BUX |
| -------------------------------------------------------------------------- | ------- |
| Run an agent on complex SaaS dashboards (Azure, Google Workspace, Stripe)  | Yes     |
| Trigger long-running tasks from Telegram while away from your machine      | Yes     |
| Keep Claude Code session context across days                               | Yes     |
| One-off scrape that finishes in seconds                                    | The [SDK](/quickstart) is simpler |

## How it works

1. You provision a BUX VM from the cloud dashboard or CLI.
2. The VM boots from a prebaked AMI with Claude Code, Browser Harness, and a remote browser already running.
3. You send instructions over Telegram, the web terminal, or SSH.
4. Claude Code drives the local Chrome through Browser Harness; when login is required, BUX surfaces a live browser URL so you can authenticate once.
5. Cookies and credentials are saved to a Browser Use Profile so the next run skips the login step.
