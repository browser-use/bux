A BUX is a cloud virtual machine that boots in 30 to 60 seconds with Claude Code and a real Chrome already running. You send it tasks from your phone (Telegram), a web terminal, or SSH, and it keeps working when your laptop is closed.

Use BUX when:

- The agent needs to log in (Azure portal, Google Workspace, Stripe, GitHub).
- The task takes long enough that you'd rather get a Telegram ping than babysit it.
- You want one Claude Code session that survives across days.

For one-off scrapes, the [Cloud SDK](/quickstart) is simpler.

<Note>
  Want the backstory? Read the [BUX launch post](https://browser-use.com/posts/bux-launch-blog).
</Note>

## How it works

1. You provision a BUX VM from the dashboard.
2. The VM boots from a prebaked AMI with Claude Code, Browser Harness, and headful Chrome.
3. You send instructions over Telegram, the web terminal, or SSH; all three attach to the same `tmux` session.
4. When a task hits a login wall, BUX hands you a live browser URL. You sign in once; cookies are saved into a Browser Use Profile and reused next time.
